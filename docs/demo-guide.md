## 从零体验

1. boss 创建会议，设置实际会议时间，选择张三、李四等参会人。
2. 提交短会议文本，或者上传清晰普通话 mp3/wav/m4a。默认上限 50 MB、10 分钟，建议先用 1—3 分钟；文本不超过 12000 字。
3. 录音自动排队转写，再分析并发布有效任务。查看摘要、决策、任务和待补充事项；没有明确负责人的事项不会随意派给某人。
4. 转写有错时展开文本并选择“使用此文本纠错”，编辑后提交新版本。已存在任务不会重复自动派发，管理者可以编辑或选择补建。
5. 员工登录查看自己负责或协作的任务；负责人可开始、完成、重开任务，协作人可填写进展。
6. Boss 查看首页和任务动态，修正人员、期限或内容。仅参与任务而未参会的员工可以看任务摘录，不能借此下载录音或查看会议全文。

失败会显示原因，可重试对应阶段；已保存的转写会复用。转写期间若提交了更新内容，旧转写不会覆盖它。每场会议当前只展示最新录音，不做多文件合并或说话人区分。

## 查询助手

- 免费：页面固定查询按钮；“查找会议：接口清单”为关键词；“语义检索：接口资料由谁整理”为本地向量检索。
- 真实自由问答：例如“会议里关于接口清单作了什么决定？”，模型选择至多一次授权查询，基于实际来源回答。通常一次请求，需会议内容回答时至多两次；没有依据时说明未找到。
- 结果只在当前账号权限内，会议检索只用最新输入版本；点击来源可看原文和版本。相似会议可能一起返回，应按会议标题核对。旧引用仍需通过当前权限检查。
- 助手没有修改任务、任意 SQL 或提权工具，每次问题独立处理。
