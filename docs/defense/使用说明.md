# 答辩演示使用说明

主文件：MeetingFlow-答辩演示.html。备用文件：MeetingFlow-答辩备用.pdf。逐页内容和参考讲法见逐页讲稿.md。

## 播放

1. 用 Chrome 打开 HTML 文件，可以直接拖入浏览器。无需启动 MeetingFlow，无需联网。
2. 按 F 全屏，方向键、空格或翻页笔的 PageUp/PageDown 翻页。Home/End 到首尾，数字 1–8 跳页。
3. 按 N 查看本页讲稿，只用于排练；现场投影前关闭。按 H 查看帮助，Esc 关闭讲稿或帮助。
4. 末页可打开本机会议和任务页面，需要 MySQL、前后端服务已启动且有登录会话。幻灯片不会自动登录或调用模型。

## 文件携带与备用

HTML 已内嵌截图和样式，不依赖外部网站或单独图片。复制该文件即可播放；PDF 适合提交老师或换电脑应急，PDF 没有动画。两者均为 16:9、8 页，主讲约 5 分钟。

本次没有生成 .pptx 文件。若提交系统仅允许 .pptx，应另行转换或制作，不要只改文件后缀。当前采用常见中文系统字体，换电脑后建议先打开检查。

封面仅放项目名，没有虚构个人姓名、学校或班级。文案可以在 HTML 中编辑，修改后 PDF 不会自动更新。修改这套文件不影响项目业务代码。

注意：会议、任务和统计截图代表验证时的数据，不代表今天的实时数量。模型语音样例为本地合成，实际识别可能有错字。
